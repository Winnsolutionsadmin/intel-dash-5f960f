Read this first

A bounce rate is a measure of your tracking before it is a measure of your visitors.

GA4 does not observe bounces. It observes engaged sessions and subtracts them : a session counts as engaged if it runs past ten seconds, reaches a second page, or fires a conversion. So a page with no scroll depth, no CTA click and no conversion event can post an alarming bounce rate while readers sit and read it, and a page with a chatty automatic event can post a comfortable one while nobody ever makes contact.

This dashboard therefore treats bounce as a derived, gateable figure. Where a page is missing an element that engagement depends on, the bounce cell renders locked only where no measured value exists, and the fix listed is an instrumentation fix rather than a copy change. Advice given on an unmeasured page is guesswork wearing a percentage sign.

bounceRate = 1 − engagementRate  ·  engaged = >10s ∨ 2+ views ∨ conversion
